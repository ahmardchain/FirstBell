# Funding assets

- Blue avatar: a raster crop of the Portfolio reference supplied by the user, stored as a PNG data URL in `lib/portfolio-avatar.ts` so the original pixels are preserved.
- USDT and BNB: https://github.com/spothq/cryptocurrency-icons (MIT), `svg/color/usdt.svg` and `svg/color/bnb.svg`.
- Visa, Mastercard and Binance: https://github.com/simple-icons/simple-icons (CC0), the corresponding brand SVG files. Brand trademarks remain their owners' property.
- Coinbase: the existing local company mark in `public/assets/marks/coinbase.svg`.

The interface displays only the network/assets/payment types supported by FirstBell's existing funding flow. Badges are not claims of partnership.
